# Universal workbench continuation

The founder's Universal Halo Modding Workbench directive is retained as the next engineering continuation. The safe master consolidation takes priority; this list does not claim these integrations are complete.

- Inventory existing adapters before adding tool registrations. Extend capability-aware handoffs for MEK/Mozzarilla, Refinery, Osoyoos, Blender tools, Reclaimer, Assembly, Excession and compatible legacy tools.
- Keep native source, dependencies, authored scenario placements, BSP detail, collision and visibility data through external editing and native compilation. General geometry reimport remains subject to preservation review.
- Provide actionable dependency setup, per-map tool context, stable external-save detection and recoverable source revisions. Keep validator identity separate from an unconfirmed writing tool.
- Continue native model, material, decal, teleporter and spatial sound acceptance using owned inputs; do not label editor preview parity as gameplay parity.
- Continue guarded live editing, arbitrary spawning/BSP replacement, game-peer replication and gameplay acceptance. Existing capability refusals remain in force until a real runtime path is implemented and verified.
- Preserve One Halo protocol experiments and private discovery. MCC-to-community-runtime cross-play remains research, not a working join adapter.

Each new integration needs its own supported-format boundary, license review, isolated native acceptance and accurate feature-ledger entry. Links and launch buttons alone are not completed integrations.

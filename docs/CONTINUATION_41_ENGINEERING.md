## What changed

`spark_core::smart_edit` defines typed numeric, persistent-placement, structural-source and existing-object live intentions over the current Project. The desktop resolves exact cache/runtime/tool/source capabilities, retains a window-owned expiring plan, and re-resolves its saved fingerprint/source/capabilities before execution. Automatic selects the first available verified route; a manual method cannot bypass its hard gates. One pending plan per window/map replaces earlier previews. Persistent plans expire after five minutes; live plans after ten seconds.

The storage adapters remain the existing cache, extraction/native compiler, accepted working-tag revision, QuickForge/BSP and exact-build MCC live services. No Halo schema or cache format is invented. The new direct transaction does not call extraction or a compiler. Persistent publication and temporary memory updates are different outcomes in the same typed plan/receipt flow.

The direct writer has an independent allowlist narrower than the inspector's readable schema. It requires exact tag ID/class/path/native offset and expected original bytes, disjoint ordered four-byte cells, unchanged placement identities, finite native values, matching source hash and MCC cache 13. It refuses compressed/extended/repaired/legacy caches, structural array/reference/model/scale changes and known source-only features. A synthetic parser fixture cannot be published as a game map.

It writes an isolated candidate, runs only `invader-crc --fix-header` on that candidate, and invokes pinned `invader-info` protected/stub/CRC checks on input and output. Every byte is compared against the source and planned cells; only the reviewed MCC header checksum cell may additionally differ. Reopening verifies the intended semantics, tag count, output identity and unchanged project/source. A validated owned `mcc-direct` output has a project snapshot, exact byte diff, tool hashes and `smart-edit-receipt.json`; normal output-integrity/readiness checks protect opening it. Failed candidates remain evidence, never successful build records. Opening a direct output labels it “edited copy,” preserving the source tab.

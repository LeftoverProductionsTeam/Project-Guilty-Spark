Handoff integrity
Use the existing workflow:

Spark → specialist tool → externally edited source → Spark reconciliation → native validation → game.

Keep exact source roots, revision hashes, dependency graphs, file ownership, Undo and rollback.

Launch only documented interfaces. Do not invent Mantle or Baboon automation endpoints.

Acceptance
Complete a round trip through at least one native tag editor, one DCC/geometry tool and one native compiler.

Confirm external changes are detected, reconciled and built without losing original files or user history.

The best integration makes the correct specialist tool feel like a natural extension of Spark.

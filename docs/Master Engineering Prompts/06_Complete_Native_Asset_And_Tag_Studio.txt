Native exports
Create standard Halo tags through validated serialization and source compilation.

Maintain correct dependency closure.

Use direct .map editing only for proven safe bounded operations.

Use loose-tag reconstruction and native rebuilds when structural edits require them.

Scriptable asset workflow
In the object's Inspector, provide a Logic / Events section for attaching supported reusable behavior.

For instance, a door may have a trigger relationship; an encounter controller may start a script; a supported effect may run when an event occurs.

Store the editable logic template in optional Spark metadata.

Compile gameplay behavior into standard HaloScript and native scenario object references.

Do not invent script fields inside arbitrary native weapon, vehicle or scenery tags.

Asset fidelity diagnostics
Compare original and output:

Normal orientation.
UVs and material assignments.
Texture channels and alpha.
Mipmap chains.
Rig hierarchy and rotations.
Animation timing.
Collision shapes.
Physical constraints.
Sound decoding and sample bounds.
Tag reference validity.
Warn about documented Blender conversion limitations and unsupported target features.

Preserve source-native appearance as much as possible, but never claim that a modern shader preview equals the exact stock game renderer.

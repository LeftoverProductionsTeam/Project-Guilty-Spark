GulchCE research
Verify the canonical repository and pinned experimental build.

Test whether selected MCC Halo 1 maps actually load without conversion.

Direct map loading is a separate capability from creating editable native tags and joining MCC multiplayer sessions.

Beyond Halo 1
The idea of backporting Halo 2 maps is a legitimate research challenge, but H2 geometry, tags, scripts, assets and rendering systems are not interchangeable with Halo 1.

Only create independent, supported conversions with explicit loss and gameplay reports.

Do not claim universal one-click Halo 2-to-Halo 1 conversion.

Acceptance
Complete independent game playtests for:

One supported CE → MCC conversion.
One legacy Mac/Xbox → compatible native target conversion.
One MCC direct-loading experiment if a verified fork is available.
Keep original hashes unchanged.

Universal means understanding each format accurately, not rewriting a header and hoping the engine accepts it.

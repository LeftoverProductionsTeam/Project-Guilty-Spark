## Decisions

1. Keep parsing, writes and process execution in Rust. Frontend edits carry field identities and values, not arbitrary binary write instructions.
2. Preserve source files and use a durable library plus versioned JSON project descriptors. Read-only inspection is the import default.
3. Render real collision BSPs as clearly identified collision geometry. Do not substitute an invented environment.
4. Use Invader as a separately installed process backend. A tool returning zero is insufficient: per-tag extraction errors, target version/scenario and CRC must also be checked.
5. Keep validation levels explicit: inspected, structurally validated, packaged/registered, and game-tested are different outcomes. There is no automatic "playable" state.
6. Preserve official Excession metadata instead of manufacturing an undocumented schema. This deliberately leaves a real external dependency.
7. Treat safe runtime/live/VR capabilities as negotiated boundaries, not features implied by a desktop preview.

The GitHub connector and native desktop-inspection helper were unavailable during this run. Primary source files were read directly, and actual native UI checks/screenshots used a local WebView CDP connection. No service messages or uploads were sent.

# C35 owner acceptance: game capture and longer takes

The [r4 Director report](C35_DIRECTOR_RECORDING.md) covers the automated native Editor Render / named-take workflow. OS Save and display/window pickers, actual game audio/capture, longer takes and physical 4K remain owner acceptance steps.

The latest [conversion repair pass](C35_CONVERSION_RESOURCE_REPAIR.md) also needs an Alpine retail MCC check: use matching classic bitmap tags, explicitly select MCC multiplayer UI dependencies, convert and open the validated result, then install it with the exact Excession metadata. Load it in anti-cheat-disabled MCC and check spawning, modes, HUD, collision, materials and sound. The native compiler/editor receipt does not certify those gameplay results.

Use the C35 development executable, an owned map and a new output filename. Keep your ordinary map edits saved first. This test does not require a live memory-edit connection.

1. Open the map in Level editor. **Menu** opens the workspace drawer; **Window** opens project/search/window controls. Close them, press **F11**, open/close one tool drawer and press **Escape** to restore the window. Confirm your map, camera and edits remain in place.
2. Prepare a useful view and select **Recording Director ↗**. Confirm the same view appears, move the Director to the desired monitor, and try fullscreen/hide interface. Escape restores its controls; Dock back retains the composition.
3. For an actual Halo/OBS test, launch your game normally. In Director choose **Live Game Capture**, then explicitly select the intended game window/display in the OS picker. Confirm the feed and whether an audio track was supplied. This captures the game's current camera; an independent MCC spectator camera is not available. Leave the game focused and move your character. Confirm the feed continues without taking gameplay input.
4. For the OS Save test, leave the folder under **Recording output** empty. Choose **Record video…**, select a **new `.webm` filename**, complete the countdown, record about ten seconds, pause/resume once and stop. Reopen that file and check the first second, the rest of the picture, audio if supplied, and the final frame. Report whether the file saves/plays correctly and whether movement/audio stay synchronized. A remembered folder and named take are also available. Editor Render is video-only.

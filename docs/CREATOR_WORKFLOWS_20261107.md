## Reproduce through Spark

1. Connect the installed H1A editing kit and Invader in Games & Tools. Connect the legitimate CE maps with their matching bitmaps/sounds/localization banks. Source edition is independent of the hosting selector.
2. Create an MCC QuickForge source or open a built MCC source-bound project. In Asset library choose the donor map, category and asset name, then drag its actual preview into the viewport. Wait for native dependency validation.
3. Use Inspector to transform; Ctrl+C/V duplicates with a new placement identity. Ctrl+Z removes that operation and Ctrl+Y restores it. Save, close normally and reopen.
4. Build through the existing native route. Inspect the opened build, then use the separate target game's supported package/scene-test workflow. Game interaction remains an outstanding acceptance step.

Use scripts/verify-source-only.mjs with SPARK_VERIFY_STAGES=sparklink, a source-matched app manifest, SPARK_QA_SHARED_CHUPATHINGY=1, SPARK_TEST_CE_SOURCE_MAP pointing to the owned CE609 map and SPARK_TEST_CHUPATHINGY_ROOT to the inspected matching client. Supply the owner-installed H1A kit, CE map as the unused archive argument (the CE branch performs its own bounded native recovery), and verified Invader. Reuse is refused if production source or executable identity differs. The wrapper exports compact evidence and disposes compiler/tag/WebView/runtime scratch. Do not invoke the harness directly into the repository.

For creators with matching admitted source: create a Chupathingy-target multiplayer project, use BSP Workshop's existing template/material/start controls, configure its compatible CE target in Project setup, and review any known source corrections explicitly. Use Online→Host game→Private Chupathingy dedicated server→Use current CE build→Start private dedicated server. Native map identity exposes the build/hash. Restart map replays the current immutable build; it does not adopt newly compiled source. Stop affects only the owned trial.

# C33 research digest

Checked 2026-10-26. This source-linked, rewritten digest adapts descriptions from **The Reclaimers Library / c20 contributors** and retains **[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)** for this document. Wording and organization were changed for Spark's implementation notes. Consult each original page for its acknowledgments and current details.

- [H1 cache/resource maps](https://c20.reclaimers.net/h1/maps/): bitmap resource headers identify type 1; resources carry paths and spans. A resource file has no independent game-version stamp. Spark proves each supported image using the selected map's generation/layout, exact index key, bounds and source/resource hashes; it cannot certify all contents by filename.
- [Bitmap data](https://c20.reclaimers.net/h1/tags/bitmap/): format 6 is RGB565; 14–16 are DXT1/3/5. External, swizzled and unsupported image layouts must be treated distinctly. C33 adds RGB565 and retains rejection of unsupported swizzling/volumes.
- [Environment shaders](https://c20.reclaimers.net/h1/tags/shader/shader_environment/) and [model shaders](https://c20.reclaimers.net/h1/tags/shader/shader_model/): base/diffuse and detail maps have different roles; model flags include two-sided and inverted alpha-test behavior. A normal-map alpha channel is not universally surface transparency. Spark supports a bounded subset, not the whole Halo shader pipeline.
- [H1 editing kits](https://c20.reclaimers.net/h1/h1-ek/): H1A's source tools can help author CE content with compatible base tags and feature limits, followed by a CE-targeted Invader rebuild. It is not universal binary conversion. Standalone loads editable tags and is useful for real-engine iteration; source staging and actual launches remain separate evidence gates.

Independent primary sources also checked: [official CE kit listing, app 1532190](https://store.steampowered.com/app/1532190/), [Microsoft tools overview](https://learn.microsoft.com/en-us/halo-master-chief-collection/general/overview-tools), and [Invader resource writer](https://github.com/SnowyMouse/invader/blob/master/src/resource/resource.cpp). Invader's independently inspected retail index uses exact tag-plus-image names; its CE index groups raw pixels separately. C33 verified those structural facts against owned resource entries. No upstream implementation code was copied into Spark.

MCC ipak is a separate resource format. Direct decoding is incomplete. The supported alternative is local editing-kit/tag extraction followed by exact user-selected DDS/image matching, retaining only references in exported projects. Full detail/blending, Anniversary rendering, environment/sky parity and same-map original-game comparison remain open unless the engineering report records actual proof.

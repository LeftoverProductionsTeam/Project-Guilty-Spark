- Games & tools begins with **MCC, OpenCE, Chupathingy and Custom Edition**. Cards glow only when the native runtime report confirms a connected installation. A connection is not proof of game compatibility or a live session. Legacy editions remain build/export targets rather than cards here.
- Selecting a runtime and map scopes the tool catalog and launch request to those exact identities. Installed GUI tools can open a scratch workspace; managed map-editing actions use the existing source handoff. Missing or wrong-kit tools retain setup actions and execution gates. - Working compiled-map saves are checked every two seconds and inspected only after becoming stable. Clean maps reopen as preserved revisions. - Online uses one runtime toolbar and the matching hosting setup. CE retains native private hosting; community runtimes prepare checked private server profiles; MCC uses its matching hosting guide. Saving a community profile does not start a server. Public form choices are remembered separately per map/runtime; control tokens remain in memory.
- Search aliases have distinct React keys; empty-workspace actions use valid container markup. Smaller layouts retain reachable controls instead of hiding required actions.

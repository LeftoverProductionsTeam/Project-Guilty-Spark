The researched ChupathingyCE README distinguishes Xbox, PC, CE and HaloMD map folders, and advertises online co-op/cross-play subject to network versions. OpenCE documents Xbox base maps and a separate CE map family. Those upstream claims are not Guilty Spark integration results. See [primary sources](RESEARCH.md).

## MCC packaging dependency

An **unpublished Excession Halo1 package configured for the exact source scenario** is required. Guilty Spark checks known identity/version fields and scenario references, copies supported metadata/images, gives the local package its project GUID, and adds the validated map. It preserves official map metadata rather than synthesizing undocumented fields.

This is not a complete official-schema validator. Required image/game-variant/shared-content references and version compatibility still need verification with Excession and MCC. Current packaging supports one map per generated package. A mismatched or absent template is a hard blocker. No template or proprietary SDK component is bundled.

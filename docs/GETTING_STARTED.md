# Connect your first Halo project

For full MCC H1 loose tags, open Runtime & Tools details or the selected tag’s Baboon panel. Choose the complete reviewed portable folder, save in the external editor, review stable-save integrity and field findings, keep a new revision and Build working tag edits. Failed integrity checks block acceptance/builds. Restore starting source creates a new verified recovery copy. See [C37 setup and limits](CONTINUATION_37_ENGINEERING.md).


**Menu** opens the workspace drawer. The title and map tabs share one compact header with upper-right native window controls. Ctrl+Backslash opens navigation. Objects, Object tags, Asset library, Map sounds and other utilities open as drawers without changing the viewport. F11 uses one fullscreen mode with thinner bars; map tabs, editing controls, audio and runtime actions stay available. Escape closes a drawer before leaving fullscreen.

For native edition checks, open **Build & playtest → Portability Lab**. Choose existing runtime profiles, inspect findings, verify untouched bytes and save the readable/JSON report. Use the supported MCC build path, then **Review native changes** before game testing. [Portability policy and scope](NATIVE_PORTABILITY.md).

Click a map object to edit its typed tags in the Object tags drawer. Asset library searches the maps you have open and accepts source model/sound placements plus custom OBJ/WAV/OGG imports. Imported-cache model additions are previews until supported model/scenario compilation. Map ambience plays automatically; use the compact mute and volume controls or Map sounds for the full spatial mix. [Viewport and audio workflow](C35_VIEWPORT_WORKFLOW.md).

1. Open Spark → **Start here → Connect Your Halo Games**. Check which game runtime is found. Multiple editions can be registered through Play & servers → Runtime adapters. Choices are remembered.
2. Open **Settings → Dependencies & setup** for missing tools, resources or source assets. If MCC is installed but Map Builder is absent, review **Open Steam install UI** for the separate free [Halo: CE Mod Tools - MCC](https://store.steampowered.com/app/1532190/), or use Steam Library → Tools. Spark shows the exact Steam executable and destination before handing off. Steam manages installation; follow the supplied extraction instructions in a fresh working copy. Spark does not execute its batch files or overwrite stock tags.
3. Select the editing-kit folder, its generation and **Editable Halo Tags**, then choose **Check and connect editing kit**. Header/hash checks identify files; they do not prove the tools ran or a tagset is complete.
4. Import your own map in Map Library. Spark preserves a managed copy and records its identity. Open Level Editor. If shared images are needed, choose **Locate Halo Textures** and select the map's original resource folder. The source/index/image-span checks must pass. Supported MCC packs and internal rebuilt-map images have dedicated readers.
5. For an original level, create a QuickForge project. Add separate MCC/CE configurations under Build → Engine build targets. Each needs its own compatible editable tags, kit and Invader installation. No map binary is universally interchangeable.

To download a Custom Edition map inside Spark, open **Community maps** and choose a catalog release with **Download into Spark…**, or paste its author's direct HTTPS `.map` or `.zip` link. Choose Level editor, Tag editor or conversion. Spark preserves the original download and imports all map candidates without replacing an open draft. Some publisher pages open in your browser and need their actual download link; Workshop installation uses Steam. Unsupported resources, protection or features remain explicit conversion blockers.

The bottom **Runtime & Tools Dock** follows the active map. Sapien, Guerilla and Standalone previews show the actual tool and derived working tags. After saving and closing those tools, use **Build working tag edits** in dock details to compile their current files, then open the separate verified output. This differs from rebuilding older QuickForge brushes. Game loading remains its own test.

For validated derived tags, the dock also shows **N saved tool edits** after stable saves. Open it to review changed paths, or use **Scan tool tags now** in runtime details. Working-tag builds compare against their verified compiled inventory; other supported source jobs compare against the files present when monitoring connected. The new cache opens separately and your original authoring project remains available. See the [saved tool-edit workflow and limits](C35_TOOL_EDIT_FOLLOW_THROUGH.md).

For HMT or another compiled-map editor, open **Changes**, expand **External editor files** and copy the working map path. Spark checks stable external saves every two seconds. Clean maps refresh as new preserved revisions; if Spark has authored edits, choose **Open changed map and keep Spark edits** to retain both tabs. The read-only preserved copy is never the external editor's write target.

**Editable Halo Tags** describe game objects, materials and scenarios. **Halo Textures** are images used by some compiled maps. **Map Builder** compiles source into a target-specific map. Source images/models live under the kit's data folder; temporary compiler jobs and caches belong to Spark's managed local data, not the original game directory.

World/QuickForge: left drag orbits, middle drag pans, wheel zooms; hold RMB to look and RMB+WASD to fly, Q down/E up, Shift for speed. Use the wheel while holding RMB to adjust flight speed. The **Camera** drawer includes navigation bindings, speed and sensitivity. Open Objects and select an object for its gizmo. Use the Preservation record for manual snapshots and a previewed restore; Settings controls the periodic interval and retention.

Imported maps open near a source player start when one exists. Use **View from player start** to choose another, or **Frame scene (F)** for the overview. Source fog can strongly haze the distant overview. **Restore source appearance** clears saved rendering overrides; it does not bake new game lighting.

Open **Map sounds** in the World inspector, search a tag path, load a permutation, then press **Play sample**. **Locate Halo Sounds folder** connects the original resources directory when sounds.map is needed. Shared samples must match their exact indexed tag/pitch/permutation and recorded hash. Looping an individual preview sample does not reproduce the game's looping-track transitions or spatial mixing. Tag editor exposes supported attenuation/pitch/gain and looping-track fields; compile and test changes in the matching game.

Halo and tool choices are remembered after onboarding. **Features** offers searchable rundowns and links into the tools; **How to / glossary** explains the terminology. Open several maps as tabs and move between Level Editor, Tags, Build and Machinima: each map retains its place and configuration. Save before handing a map to another window. **Open compiled map** opens a verified build in a separate preserved tab so its actual output geometry and textures can be reviewed.

In an imported map's Level Editor, open **Construction → Connect another map’s BSP** to select another preserved map and one of its sections. Choose matching editable donor tags, adjust the transform and tunnel floor points, apply the draft, check source clearance, then build. Native topology, lightmaps, compiled collision and cache checks must pass. A manual walk in Standalone and a retail MCC cache test remain separate acceptance steps. Runtime BSP replacement is unavailable.

The connection draft names its actual donor and shows the tunnel length and current steps. Selecting a different donor preserves the draft until you plan again. **Return to current draft** restores its selection; **Reset draft to applied connection** discards only unapplied connection changes. Enable **Rotate around tunnel entrance** to change yaw without moving the mouth. A failed clearance check identifies the route segment and world coordinates to adjust.

For a single-BSP donor, **Include donor source scenery** retains its scenery models and placement settings in the compiled world. Check the reported count and inspect the actual output with **Open compiled map**. Donor gameplay objects and scripts are separate; see [donor scenery](DONOR_SCENERY.md) for supported settings and limits.

To extend a completed connection, open its compiled map and add another donor there. Newly imported MCC outputs keep a tool profile pointing to their own editable build tags. Use **Browse donor tags** for the new donor. The Level Editor status bar's **Viewport performance** panel helps inspect the cost of a larger world; [three-map workflow details](THREE_MAP_WORLD_AND_PERFORMANCE.md) distinguish editor, compiler and game acceptance.

For animation, drop a supported JMA/JMM-family source into Machinima, select a matching biped and rehearse its actual skeleton. Assign a custom action or a complete compatible animation graph and rebuild for engine changes. Native recording uses the SDK take controls: choose a camera, build, launch the take, and record the game window in OBS. See [Standalone workflow](STANDALONE_WORKFLOW.md).

For the new **Recording Director ↗**, prepare the Level editor view and pop it out to another native window. Dock back retains the same camera session. Editor Render uses Spark's renderer; Live Game Capture explicitly asks you to share a window/display. An independent MCC spectator camera is unavailable. The [Director test card](CONTINUATION_35_TEST_CARD.md) covers the remaining Save-dialog, recording startup and actual game/audio acceptance.

Complete game shader parity, arbitrary cross-engine conversion and universal game acceptance remain incomplete. Legal source images can be matched without bundling their bytes in project exports. Read [compatibility](COMPATIBILITY_MATRIX.md) before building.

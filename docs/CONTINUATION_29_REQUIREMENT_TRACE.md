Companion applications are optional extras for historical workflows, not replacements for an actual integrated Tag Editor, scenario/geometry editor, source build and playtest. Preserve the original independent modding culture and artist credits without bundling third-party IP.

**This release's accepted engineering increment:** It closes the missing *metadata-only preview* step of cross-map tag transplant planning. It does not claim error-free binary transfers, a verified built map, or closed P0 priorities.

# Add checked private Custom Edition hosting to Online

Online → Host game now offers an actual classic CE dedicated server instead of a generic community-host form for that runtime. Users choose a registered native multiplayer map, stock mode and player limit; Spark creates a checked private game copy and exposes start, native map status and stop in one compact panel. Advanced name/port and diagnostic output stay collapsed. Controls survive workspace reloads.

The server remains loopback-only with public listing disabled. Window-scoped ownership rejects cross-window/stale controls, and Windows job objects stop owned servers after abrupt Spark termination. Fixed executable/configuration selection, source/copy integrity checks, bounded status parsing, port checks and retained evidence protect the existing game and native source workflows.

Validation: real desktop UI/native IPC and CE engine tests cover Blood Gulch, five stock game types, the unchanged compiler-produced CE Workshop cache, independent server ownership, scoped/abrupt shutdown and changed-input refusal. The original 127-file game installation is unchanged. Exact application identities, measured timings and final regression totals are recorded in [the native acceptance receipt](fixtures/ce-private-host-native.json).

Public/LAN exposure for this new classic CE control, direct selection of managed build outputs, arbitrary live BSP/object delivery, game-peer replication, networked AI and universal runtime conversion remain open. C35–C39 history, Baboon/Invader/source safeguards and the unfinished direct compiled-map research are preserved.

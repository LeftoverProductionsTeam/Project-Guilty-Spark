# Continuation 27 - 07 Halo Modding Brain historical workflow lab

**Baseline:** exact recovered C26 source ZIP, independently verified with its SHA-256 and `unzip -t` before modification. This is an **additive, cumulative SOURCE-only** continuation, not a compiled Windows application, modified Halo cache, or playable game.

## Implemented

1. `src/legacyWorkflowLab.ts`: a bounded seven-workflow, source-aware legacy translation model. It uses current project source SHA, exact matching inspection, owned bitmap tag counts, editable brush count, Creator Studio availability, self-reported author/permission notes, and presence of configured tool folders. It cannot certify a compiler, tag/BSP roundtrip, collision, engine version or gameplay. No arbitrary file paths or tag payloads are returned.
2. `src/components/LegacyWorkflowLab.tsx`: a genuine React Academy surface with a historical source link, original technique versus modern workflow, current evidence checks, safe next-workspace navigation and local JSON export.
3. `src/components/Academy.tsx` + `src/App.tsx` + `src/academy.css`: the historical lab is integrated into the current project/inspection/settings lifecycle with accessible buttons and responsive Halo-inspired styling.
4. `src/tutorialAcademy.ts` + `src/firstRun.ts`: a five-stage `07 Halo Modding Brain` lesson and a seven-step-option newcomer route. Content connects old-school modding creativity to preservation, actual source editing, and compiler/engine manual gates.
5. `src/communityCredits.ts`: source-linked recognition of Eschaton, HMT, SparkEdit, SwordEdit, the MacGamingMods archive and HaloMD preservation contributors. Existing links, nominations and uncertainty policy are retained.
6. `scripts/test-legacy-workflow-lab.mjs`: regressions for seven workflows, source/inspection hash matching, invalid evidence, path-free deterministic JSON, and strict false game-proof fields. Added to `npm run test:offline`.
7. `docs/CONTINUATION_27_ORIGINAL_HALO_LORE.md`: verified reference matrix, historical restoration insights, philosophy, and open feature/acceptance map. No third-party assets or binaries incorporated.

## Safety and verifiability

- A historical source URL is read-only documentation, not a command that downloads or launches legacy software.
- The plan uses exact 64-digit SHA-256 and refuses to treat a mismatched current map inspection as the same source. No original map path or tag path is included.
- Source metadata and user-provided rights notes are **not** independent proof of ownership; tool directories are **not** proof the compiler ran.
- A saved BuildRecord status is never promoted to an in-game success. `compiledBspVerified`, `collisionVerified`, `tagRoundTripVerified`, `gameRuntimeVerified`, and `legacyEngineCompatibilityVerified` are always false.
- Source-only engine exports, external tag editing, BSP CSG and native compilation retain their previous blockers; C27 does not claim to repair general BSP/collision errors.
- Windows Tauri, Cargo/native, real owned map UI pixels and actual gameplay require validation on the owner's matching toolchains.

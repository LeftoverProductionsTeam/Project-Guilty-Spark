# Halo CE original tutorial writers — research-backed Academy catalog

The interactive Guilty Spark Academy lessons are newly authored and **must not** be attributed to the historical writers listed here. These real authors created tutorials that influenced the techniques and workflows. All links point to independent archived indexes rather than copies inside the game editor.

Its GPL-3.0 source has NOT been copied or linked into Guilty Spark. Native gametype parsing/CRC would require an independently reviewed, tested implementation and appropriate license compliance.

## Standards for adding credit

1. Prefer creator-authored posts, repository credits, original archive index entries, or dated forum captures.
2. Attribute precisely the documented work, not hypothetical features or an identity inferred from an alias.
3. Link to sources; never bundle old third-party executables or copyrighted tutorial images without authorization.
4. If an author cannot be independently confirmed, retain an 'unknown/unverified' label rather than inventing a name.

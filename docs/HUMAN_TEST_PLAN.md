4. Test Undo/Save and rebuild again. Confirm the previous layout returns. Check floor, doorways and any seam with actual player movement; engine ticks do not establish these checks.
5. Give a material a missing native shader path and request a rebuild. Expect a useful error and the prior game revision to remain active. Undo and save the invalid edit.
6. Switch maps or open another workspace window. It must not rebuild/stop a different window's session. Stop playtest, close/reopen Spark and verify saved source and build history remain. Generated playtest scratch should be disposed.

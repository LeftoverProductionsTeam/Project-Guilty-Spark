[Pinned source/release research](research/C36_COMMUNITY_INTEROPERABILITY.md) distinguishes Chupathingy's legacy/range and Delta wire identities, OpenCE native/browser behavior, separate Warthog homebrew boundaries and Halo-3-only Project Reclaimer releases. The owner's Xbox image arrived after the initial R1 package was prepared. Its SHA-256 is **`bbed30485a34fb971687648f31a8b50467c92d7ef296e3f97bad51372db1b012`**; bounded read-only range copies provided verified cache-5 UI/Blood Gulch/A30/Carousel fixtures. The original image was rehashed unchanged. Publisher-signed **Chupathingy v0.8.1c** and **OpenCE build-329** clients then ran as independent native processes on isolated loopback addresses with separate data/save/log roots. No system install, public server, sharing/downloads, router/firewall change, anti-cheat bypass or new protocol was introduced.

**OpenCE/OpenCE**, **Chupathingy/Chupathingy** and **OpenCE host → Chupathingy client** joined and simulated Blood Gulch. **Chupathingy host → OpenCE client** was explicitly rejected as host network 32 versus client 39. Both processes exited normally in the completed trials; host logs continued after client departure and entered game-over, rather than establishing a continuing joinable match. This exact asymmetric result must not become a general cross-version rule.

Independent analysis of the OpenCE baseline found all **47 shared ticks / 94 player snapshots** identical at printed precision for alive/dead, health/shields, score/kills/deaths, team and machine. Position deltas reached **0.09245 world units**; three sampled grenade values differed. Native SHOOT invokes weapon impact damage directly, and KILL forces native death/respawn. This verifies scoped impact-damage/state replication, **not trigger input, projectile flight, aiming, complete inventory/object parity or human play**. First startup failed on missing stock Carousel before the requested map selection; adding the unchanged disc map resolved it. [Full native evidence, limitations and reproducible scripts](C36_COMMUNITY_NATIVE_TESTS.md).

Spark's listing/invitation-to-client path, authenticated remote content/version resolution, AI agreement, two computers and larger player counts remain separate gates. The exact-version listing gate remains conservative. These tests use upstream engine-owned networking and do not implement an MCC protocol bridge.

The long-term ledger retains every prior runtime and gameplay goal. Exact MCC foreign-wire translation, arbitrary live spawning/BSP replacement, game-peer edit replication, dual wield/sword/lunge, full rendering/audio parity, eight-player campaign/Firefight and staged 2/8/16/32/64/128-client proof remain open.

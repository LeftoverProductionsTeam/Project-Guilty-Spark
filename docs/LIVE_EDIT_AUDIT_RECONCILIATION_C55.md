## Source checks and scope

[Baboon v0.2.2 release notes](https://github.com/Zoephie/Baboon/releases/tag/v0.2.2) describe narrow, build-identified Campaign Evolved poking, rollback and an explicit prohibition on allocating/resizing/registering new runtime content. That is a design benchmark, not Halo 1 adapter evidence. [Baboon v0.3.2 release notes](https://github.com/Zoephie/Baboon/releases/tag/v0.3.2) describe fixes for active-kit/visible-tab targeting and background ownership; record them as historical fixed behavior, not current product defects.

The [c20 Assembly overview](https://c20.reclaimers.net/general/community-tools/assembly/) separates fast cache edits from native compilation and explains that compiler-derived runtime fields matter for larger changes. This supports keeping direct compiled-map, loose-tag and geometry workflows separate. It does not establish an MCC/community-runtime protocol bridge or unrestricted Halo 1 live injection. No upstream implementation source was copied.

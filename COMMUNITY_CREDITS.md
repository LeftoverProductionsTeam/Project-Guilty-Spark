# Community credits and historical foundations

C38 continues Zoephie/Baboon and SnowyMouse/Invader native workflows, with research profiles for General-101's Blender toolset, num0005/Osoyoos, Sigmmma and MosesOfEgypt/MEK, Gravemind2401/Reclaimer, XboxChaos/Assembly, Crisp/Foundry and Microsoft's official tools. [Exact integration and licensing boundaries](docs/COMPATIBLE_TOOLS.md). No upstream program, parser or schema implementation is redistributed by these profiles.

Project Guilty Spark stands on more than twenty years of research, experimentation, documentation, tools, discoveries, and shared knowledge from the Halo modding community. This project would not exist without the people who explored the Blam engine, created the original editors, reverse-engineered file formats, preserved old maps, documented workflows, and helped generations of modders learn.

Spark continues this work. It does not claim to have invented Halo modding or independently discovered every format. The following are historical/research credits, not claims of code reuse, endorsement, employment or affiliation.

## Original foundations and historical inspiration

- **Bungie and Gearbox**: Halo and the original content/editing foundations. The later H1A kit also credits 343 Industries, Saber Interactive and other contributors; see the [official Steam listing](https://store.steampowered.com/app/1532190/) and [editing-kit history](https://c20.reclaimers.net/h1/h1-ek/).
- **HaloMods and its researchers/tool authors**: early public experiments, reverse engineering and shared lessons. Archives and later mirrors preserve incomplete pieces of this history; missing provenance is not filled with guessed names.
- **MonoxideC / Monoxide and tjc — Halo Map Tools**: early direct-cache tag and asset experimentation. The [original HaloMaps HMT listing](https://www.halomaps.org/hce/detail.cfm?fid=725) preserves its release notes and credits.
- **Grenadiac — SparkEdit**; **bobindashadows, Sword and Samuco — SwordEdit**; **Altimit01 — Eschaton**. Their visual map/tag workflows are important design precedents. Attribution is corroborated by the [c20 historical tools catalog](https://c20.reclaimers.net/h1/community-tools/obsolete/); this is not a claim that their implementation is embedded in Spark.
- **MacGamingMods, Monoman and the classic Mac modding community**: the [project-owned archive](https://www.macgamingmods.com/) preserves Halo Demo/MD releases and tool listings. **Fonzie / Fonzeh**, Patrick Davis and other names retained in the supplied mod readmes remain credited with those artifacts; ambiguity about aliases/authorship is preserved in [the archaeology](docs/ZOMBIE_APOCALYPSE_ARCHAEOLOGY.md).
- **HaloMaps**, **HaloMD** and their community archivists: maps, utilities, documentation and preservation. References: [HaloMaps](https://www.halomaps.org/), [HaloMD](https://www.halomd.net/).
- **CE3**, **PopeAK49, Higuy, Jesse, MattDratt, MosesofEgypt** and the tutorial creators named by its [own tutorial index](https://haloce3.com/tutorial-index/): accessible instruction in level creation, terrain, scripting, HUDs and model workflows. Historical tutorials need version/context review before use today.

## Research and documentation

- **C36 native portability/detail research:** [C20 H1 tag/porting documentation](https://c20.reclaimers.net/h1/tags/) and [painted-detail hazards](https://c20.reclaimers.net/h1/tags/detail_object_collection/), plus [Invader's pinned BSP schema](https://github.com/SnowyMouse/invader/blob/696830ff80af227e84e7237c2ef26eb2301ed110/src/tag/hek/definition/scenario_structure_bsp.json) and native CLI behavior. C20 text retains CC BY-SA 3.0 attribution; the bounded preservation/checking code is original. No native game assets or Invader implementation are redistributed.
- **C36 community integration:** [ChupathingyCE](https://github.com/ChupathingyCE/chupathingyce/blob/fa0f2df4958459e82359df6f41b325a7344d477c/docs/license.md), [OpenCE](https://github.com/OpenCommunityEdition/OpenCE/blob/70c5e600ea345345db040ce1914903cc6746b46e/LICENSE) and [Warthog Xbox](https://github.com/ChupathingyCE/warthog-xbox/blob/66d1392c2cfc10d52b62d431ad2cf41844a705ad/LICENSE) retain their own licensing. Current Chupathingy/Warthog use GPL-3.0-or-later (including the documented console SDK permission where applicable); current OpenCE uses AGPLv3. Earlier CC0 policies must not be applied to unrelated repositories or modern revisions. Spark's original protected-invitation validation reuses no engine/cryptographic implementation; verified portable clients remain private test dependencies. See [exact source/release boundaries](docs/research/C36_COMMUNITY_INTEROPERABILITY.md).
- **BirchWoodGod and halo-ce-vita contributors**: the [MCC sound reader at commit cbdfb646](https://github.com/BirchWoodGod/halo-ce-vita/blob/cbdfb64645141e0175415906fb810de89ed7e2ad/port/linux/game/mcc_sound.c) documents MCC's classic sound-bank namespace. **vgmstream contributors** and **HearthSim/python-fsb5 contributors** document [FSB5 headers](https://github.com/vgmstream/vgmstream/blob/master/src/meta/fsb5.c) and [sample metadata](https://github.com/HearthSim/python-fsb5/blob/master/fsb5/__init__.py). These are format-research references for the original bounded Rust parser; upstream code and owned game audio are not copied into Spark or its source distribution.
- **The Reclaimers Library / c20 and its contributors**, including the authors acknowledged on each page, document formats, tools and engine behavior. [c20](https://c20.reclaimers.net/) text is **CC BY-SA 3.0**. Keep page links, author acknowledgments, the [license link](https://creativecommons.org/licenses/by-sa/3.0/) and adaptation notices when reusing it. Our C33 research digest identifies its summarized sources and changed presentation; independent application code is MIT, not copied c20 prose/code.
- **SnowyMouse and Invader contributors**: [Invader upstream](https://github.com/SnowyMouse/invader) is a major format/tool reference and an optional separately installed CLI dependency. It retains its GPL-3.0 license. C33 compared the documented retail per-image and CE pixel-group resource layouts with actual owned bytes; no Invader executable or source implementation is redistributed here.
- **MosesOfEgypt, gbMichelle and MEK contributors**: [MEK](https://c20.reclaimers.net/h1/community-tools/mek/) and the Reclaimer Python ecosystem provide alternative editing/extraction workflows. **Gravemind2401 and contributors' [Reclaimer](https://github.com/Gravemind2401/Reclaimer)** is a distinct file explorer, not the same software as the Python library.
- **OpenCE, ChupathingyCE and relevant community engine/network research** retain separate runtime boundaries and upstream attribution. Exact source references/revisions remain in [the feasibility study](docs/MCC_MULTIPLAYER_AI_FEASIBILITY.md). Public source visibility alone does not grant a reuse license.
- Tool authors, tutorial writers, testers, mod creators, server operators and archivists who taught others, documented failures and preserved forgotten experiments are part of this foundation even where a verified individual attribution is still missing.

## Dependencies, redistributed components and contributed content

Direct/runtime/build dependencies and their actual license expressions are listed in [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md) and the generated license inventory. Optional Halo editors/runtimes remain external. No copyrighted game map, tagset, art/audio, proprietary editing kit or archived executable is bundled.

The interface artwork/CSS and example QuickForge arena are original project work. Rendered native screenshots may show user-owned Halo content to document behavior; they are not reusable asset packs. Historical mod fixtures stay local. Creator-contributed artwork requires explicit provenance and licensing before redistribution.

Corrections are welcome through the **Historical attribution** issue type. Include an original readme, release thread, source repository or other traceable source. The in-app Community Thanks nominations remain local and unverified until reviewed.

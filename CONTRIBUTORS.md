## Maintaining attribution

Credit the original author for each imported feature or asset. When integrating upstream source, retain its license, original author and source revision in the commit history and relevant notice. Add file or project attribution to Spark’s Preservation record before distributing content. Keep each contributor’s permissions with the work. Do not bundle an asset with unknown redistribution rights. Use a private owned copy when its terms allow local testing.

Send corrections through the repository’s [historical attribution issue](https://github.com/LeftoverProductionsTeam/Project-Guilty-Spark/issues/new/choose) with the original release, readme or commit. Offer reusable improvements through the appropriate upstream project after review.
